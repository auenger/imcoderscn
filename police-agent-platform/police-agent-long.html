架构总览

"1+N" 平台架构

核心理念：1 个统一底座（权限 + 数据治理 + 模型调度）+ N 个专业 Agent（反诈研判 / 交通管理 / 社区警务助理 / ...）

N 个专业 Agent反诈 · 交通 · 社区 · 禁毒 · 网安
Agent 编排引擎低代码 Workflow + ReAct 思考链
安全与权限层零信任 · 行列级管控 · 审计全链路
数据接入层 (Data Fabric)多模态网关 · RAG 知识库 · 脱敏沙箱
演进策略：前期 Dify 式低代码配置 快速产出 → 中后期转向 Hermes / OpenCanvas 多 Agent 协同模式，支持接警→查证→布控→派单全链路自动化。

功能模块

交付与交互终端 (Omni-Channel)

移动端

接入钉钉/飞书专网版，移动处警、现场反馈。支持离线+在线混合模式。

指挥中心端

大屏/PC 网页，线索研判、逻辑推导演示。类似 OpenCanvas 交互体验。

语音交互

对接单警装备（对讲机、执法仪），语音转文字指令触发，解放双手。

外部渠道

110 接警平台（语音+文本）、政务服务网、微信小程序（需脱敏+审计）。

渠道管控策略

渠道身份双向认证（数字证书+动态令牌） → 请求频次限流 + 异常行为检测 → 输出内容渠道差异化脱敏

权限管控

三层防护体系

① 组织级隔离

  • 按警种 / 辖区 / 职级划分租户
  • 租户间数据物理 / 逻辑隔离
  • 独立资源配额 + 计费审计

② 数据级管控

  • 字段级：敏感字段动态脱敏
  • 行级：按辖区/案件归属过滤
  • 时间级：历史数据访问时效
  • 操作级：查询/导出/修改分离

③ 场景级管控

  • 基于任务上下文动态授权
  • 高风险操作二次审批
  • 紧急任务临时权限 + 自动回收

零信任原则

  • 统一身份认证（数字证书 + 生物特征）
  • 最小权限：角色 = 岗位 + 任务 + 场景
  • 短时令牌 + 操作心跳 + 异常登出
  • 全链路审计：谁 + 何时 + 查了什么 + 输出什么
产出物管理

产出物全生命周期管控

产出物类型

  • 分析类：案件报告、风险画像、关联图谱

  • 交互类：问答记录、操作日志、用户反馈

核心风险

高风险项：数据与越权

1
数据泄露

Agent 记忆缓存敏感信息、输出未脱敏。缓存中可能残留公民隐私数据。

对策：输出前强制脱敏引擎 + 记忆定期清理 + 敏感词实时拦截。合规依据：《数据安全法》《个人信息保护法》

2
越权访问

低权限用户通过 Prompt 诱导 Agent 间接查询高敏数据（Jailbreak 攻击）。

对策：引入 Independent Guardrail 独立拦截层，Prompt 进入模型前合规扫描 + 查询重写 + 结果过滤 + 双因子审批

3
专网数据出域

警务专网数据与公网大模型的物理隔离问题。数据一旦出专网即失控。

对策：必须私有化部署底座模型，数据不出专网。采用"联邦学习 + 本地部署"模式。

核心风险

中风险项：模型与安全

模型幻觉

  • 法律法规引用张冠李戴
  • 案件定性出现偏差误导决策
  • 法条引用无原文来源

防控措施

  • 关键结论人工复核
  • 置信度标注 + 知识溯源
  • 法条引用必须有原文数据库链接
  • 结构化验证引擎

提示注入攻击

  • 恶意用户通过 Prompt 窃取数据
  • 绕过权限访问控制
  • 诱导生成违规内容

防控措施

  • 输入清洗 + 意图识别
  • 安全护栏（Guardrail）
  • 沙箱隔离执行
  • 异常行为实时告警

责任归属：Agent 生成的研判建议若出现偏差，法律责任难以界定。所有产出物强制关联操作人签名，建立"影子模式"测试。

核心风险

运营与合规风险

审计缺失

Agent 决策过程黑盒，无法追责。等保三级"安全审计"要求全链路可追溯。

对策：全链路日志 + 思维链记录 + 关键节点快照。决策每一步留痕。

渠道风险

外部渠道（小程序、政务服务网）成为攻击入口。接口暴露面大。

对策：渠道隔离网关 + 输出差异化脱敏 + 频率限制 + 异常检测。

资源消耗

警务高并发场景下 Token 消耗过大导致系统响应延迟，影响紧急处警。

对策：任务优先级队列，紧急处警任务优先调度计算资源。

运维风险

Agent 配置错误导致批量误操作，影响范围广。

对策：配置变更审批 + 灰度发布 + 一键回滚机制。

实施路线

分阶段推进策略

Phase 1 · 1-3 月
基础能力建设

搭建等保三级合规环境 + 统一身份认证 → 实现 1 个低敏场景（警务知识问答）+ 钉钉渠道 → 建立数据分级标准 + 基础审计日志

Phase 2 · 4-6 月
能力扩展

接入 2-3 类内部数据源 + 字段级脱敏 → 支持多 Agent 形态（Chatbot + API + 低代码）→ 完善权限引擎：动态策略 + 临时授权

Phase 3 · 7-12 月
深度赋能

对接视频/图像等多模态数据 + 复杂推理场景 → 产出物全生命周期管理 + 智能风险预警 → 通过等保测评 + 形成可复制的警务 Agent 建设规范

核心原则：安全可控 > 智能高效。在警务场景下，宁可牺牲部分体验，也要确保数据安全和权责清晰。合规前置，早期引入安全团队参与架构设计。
