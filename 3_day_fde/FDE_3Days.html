3 天全封闭线下实战课程

从客户问题到可部署成果

为政企售前、解决方案与集成交付骨干设计。三天完成需求定义、AI Demo、全栈部署和方案路演。

课程北极星 不以“学会一个工具”为终点，以“交付一个能演示、能部署、能解释价值的行业方案”为终点。
道、法、术、器统一 FDE 的角色认知、工作方法、技术实践与资产沉淀
3:7理论输入与实战训练

课程设计总纲

把原有“道、法、术、器”方法论与培训需求中的三大模块对齐，形成一条连续的项目交付链。

一案到底，三天递进

每组选择一个政企行业场景。问题、数据、原型、代码、部署与路演全部围绕同一项目推进，避免课堂知识与交付现场脱节。

参训者画像

省、市公司政企线条售前、解决方案、项目集成交付人员。优先选拔 AI 金种子、重点项目负责人和一线交付骨干。

建议前置能力

具备基础计算机知识；可理解接口、数据表和部署概念；愿意转型 AI+DICT 复合岗位。

Customer Owner

扮演客户业务负责人，定义业务结果、预算边界与最终 Go/No-Go 决策。

FDE / Delta

负责需求澄清、Demo 生成、数据与工具接入、现场调试及交付推进。

Solution / Dev

负责技术架构、接口、代码、容器化、测试与部署，确保方案真正可运行。

Risk / Echo

负责安全、合规、权限、成本和失败模式审查。每组必须有人承担该角色。

协作机制

2-3 人 Mini 小组可一人兼任两个角色，但 Owner 与 Risk 不建议由同一人兼任。

结课时，学员必须能做到

从“客户想做 AI”走到可验收方案

识别真实业务结果、重画流程、判断 Agent 边界、核实数据与权限、设置人工接管点，并定义试点成功标准。

问题假设 → 需求证据 → 原型验证 → 部署验收

需求挖掘

完成客户访谈、Use Case Scoping、流程 Before/After、Data Source Register 与 PRD。

Demo 生成

使用 AI 编程工具生成可交互 Demo，完成提示词、Agent Role Card、工具调用与 Evals。

全栈部署

完成前后端联调、数据库与 API 接入、Docker 容器化、日志监控与现场验收。

方案表达

用业务结果而非功能列表完成 10 分钟路演，回答价值、成本、风险与推广路径。

三天详细课程日程

每天含 15 分钟晨会、两次小组站会、教练巡回指导和 19:00-20:30 开放麦。全程学习时间 1,620 分钟，其中实战与评审约 70%。

六套行业案例母题

主办方可替换为省内真实项目。所有案例均需提供客户背景、脱敏数据、接口说明、约束条件和期望业务结果。

主案例：政务服务智能预审

群众提交材料后，系统识别事项、检查完整性、提示缺失材料并生成预审意见，最终由窗口人员确认。

业务结果
减少退件与重复跑动，缩短预审时长。
关键数据
事项清单、办事指南、材料样例、历史退件原因。
风险边界
AI 不作行政许可决定，不虚构政策依据，个人信息最小化使用。
技术挑战
OCR、RAG、结构化输出、规则校验、HITL 与审计日志。

工业制造

设备故障问答与维修工单助手。重点训练多模态资料、知识检索、工单流转和安全操作边界。

教育

招生政策咨询与材料核验。重点训练高并发问答、政策时效、引用溯源和未成年人信息保护。

医疗

院内知识助手与随访信息整理。仅做信息辅助，不做诊断，重点训练敏感数据、拒答与人工升级。

文旅

目的地行程生成与客诉协同。重点训练实时信息、工具调用、个性化推荐和服务闭环。

园区运营

企业服务政策匹配与诉求派单。重点训练企业画像、跨部门流程、权限控制和进度追踪。
