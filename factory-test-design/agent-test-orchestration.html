错误诊断 Agent · 三端快速定位
错误在 MES？设备？还是 EAP？秒级定位
错误诊断是 Agent 最核心的价值。当测机人员按流程操作后某个节点 Fail，Agent 需要回答两个问题：1）错误发生在哪一端（MES/设备/EAP）？2）可能的原因是什么？这决定了问题该由谁来处理。

1. 错误捕获 · 上下文快照

节点 Fail 的瞬间，Agent 自动捕获：请求报文、期望响应、实际响应、耗时、设备状态、EAP 日志片段、MES 下发参数。所有原始数据打包为诊断上下文。

自动触发 耗时 <1s

2. 端侧定位 · 错误归属判定

Agent 按优先级逐端排查：先检查设备响应数据是否完整（设备侧）→ 再检查 EAP 服务日志是否有异常（EAP 侧）→ 最后检查 MES 下发参数是否正确（MES 侧）。通过规则引擎 + 历史模式匹配确定错误归属。

规则引擎 模式匹配 耗时 2-5s

3. 原因分析 · 深度推理

定位端侧后，Agent 进入原因分析：对比同类设备历史错误、检查是否为已知问题、判断是否为环境因素（网络/负载）、评估是否需要重测。输出结构化诊断报告。

历史比对 环境分析 耗时 3-8s

4. 诊断报告 · 处置建议

输出完整诊断报告：错误端归属、可能原因 Top3、历史同类案例、建议处置方式（重测/跳过/人工介入）。人工确认后决定是否继续流程。

原因分析 · 错误分类与处置策略
不只是定位，更要分析为什么
定位错误归属是第一步，分析原因是第二步。Agent 需要结合历史错误库、设备型号特征、当前环境状态，给出结构化的原因分析和处置建议，帮助相关团队快速修复问题。
