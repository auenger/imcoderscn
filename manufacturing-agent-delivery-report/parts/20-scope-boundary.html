四类 Agent 的最低可验收定义

产能分析 Agent

按约定组织、产线、设备、班次与人员维度查询产能，解释指标来源，识别异常与瓶颈，并可追溯至 MES 明细。

数据分析 Agent

对不少于约定周期的设备与人员历史数据进行趋势、对比、异常和相关性分析，输出结论、证据和数据时间范围。

计划模拟 Agent

读取周计划、产能约束、设备状态、人员能力与历史节拍，生成候选日计划，并清晰展示约束、冲突和人工调整点。

预测性报告 Agent

按约定周期生成生产趋势、异常风险、预测区间、影响因素与建议动作。预测结论必须附带置信度或适用条件。

验收不应只看“能否聊天”

建议同时验收数据正确性、口径一致性、权限隔离、响应时效、可解释性、稳定性、人工兜底和审计完整性。计划模拟与预测结果属于辅助决策，最终生产指令仍由授权人员确认。
