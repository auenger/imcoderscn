认识 Claude Code

什么是 Claude Code？

Anthropic 官方推出的 命令行 AI 编程助手，直接运行在终端中，深度集成你的代码库。

核心能力

  • 理解整个项目代码库
  • 读写文件、执行终端命令
  • 多步骤任务自主完成
  • Git 操作、PR 创建

产品形态

  • CLI（终端命令行）
  • 桌面应用（Mac / Windows）
  • Web 应用（claude.ai/code）
  • IDE 插件（VS Code / JetBrains）

一句话理解：Claude Code = 能直接操作你电脑的 AI 编程搭档，不只是聊天，而是真正干活。

安装

全局安装 Claude Code

前提条件：Node.js 18+ 和 npm。

# 全局安装
npm install -g @anthropic-ai/claude-code

# 验证安装
claude --version

# 首次启动（会引导登录认证）
claude

安装后首次运行

Claude Code 会引导你完成 Anthropic 账号认证。支持 OAuth 登录或 API Key 两种方式。

更新到最新版

npm update -g @anthropic-ai/claude-code
目录结构

全局配置：~/.claude/

用户主目录下的 ~/.claude/ 存放全局配置和个人偏好。

~/.claude/ ├── settings.json # 全局设置（权限、环境变量） ├── settings.local.json # 本地覆盖设置（不入 git） ├── credentials.json # 认证信息 ├── skills/ # 全局 Skills（自定义技能） ├── projects/ # 项目级记忆 & 配置 │ └── -path-to-project/ │ ├── CLAUDE.md # 项目指令（跨会话持久） │ └── memory/ # 自动记忆文件 └── scheduled_tasks.json # 定时任务

关键文件：settings.json 控制全局行为，比如自动允许哪些工具、hooks 配置等。

目录结构

项目配置：项目根/.claude/

每个项目可以在根目录下创建 .claude/ 文件夹，存放项目级配置。

your-project/ ├── .claude/ │ ├── settings.json # 项目级设置（可入 git 共享给团队） │ ├── settings.local.json # 本地覆盖（不入 git） │ └── commands/ # 自定义斜杠命令 │ └── review.md # /review 命令的 prompt ├── CLAUDE.md # 项目指令文件（可入 git） └── .claudeignore # 排除文件（类似 .gitignore）

CLAUDE.md

项目的"AI 说明书"。告诉 Claude 你的代码规范、架构约定、注意事项。每次会话自动加载。

优先级

项目级 settings.json 覆盖全局设置。settings.local.json 优先级最高（不入版本控制）。

配置

CLAUDE.md — 项目级指令文件

放在项目根目录，每次会话自动注入到 Claude 的上下文中。相当于给 AI 写的 onboarding 文档。

CLAUDE.md 示例

# 项目规范

## 技术栈
- 前端：React + TypeScript + Tailwind CSS
- 后端：Node.js + Express
- 数据库：PostgreSQL

## 代码规范
- 使用函数式组件，不用 class 组件
- API 路由统一放在 src/routes/ 下
- 提交信息用中文，格式：`类型: 描述`

## 注意事项
- 不要修改 src/generated/ 下的文件（自动生成）
- 环境变量统一放在 .env.local
多个 CLAUDE.md 可以共存：根目录一个、子目录各一个（如 src/backend/CLAUDE.md），Claude 会根据当前工作上下文自动加载相关的文件。
基本命令

启动与对话

命令说明
claude在当前目录启动交互式会话
claude "修复登录 bug"用单条提示启动，执行完自动退出
claude -p "解释这个函数"非交互模式（pipe 模式），输出到 stdout
cat log.txt | claude -p "分析错误"管道输入，结合其他命令使用
claude --resume恢复上次中断的会话
claude update更新 Claude Code 到最新版

核心交互：启动后直接用自然语言描述需求，Claude 会读取代码、执行命令、修改文件。遇到权限敏感操作会弹窗确认。

基本命令

常用斜杠命令

在交互会话中输入 / 开头的命令快速触发功能。

命令功能
/help查看帮助信息
/init初始化项目 CLAUDE.md
/review代码审查当前分支的变更
/compact压缩上下文（会话过长时使用）
/clear清空当前会话历史
/model切换模型（Opus / Sonnet / Haiku）
/cost查看当前会话 token 用量和费用
/memory查看和编辑持久化记忆
/config打开配置管理
实用技巧

快捷键与交互技巧

快捷键 / 语法说明
@file.js引用文件到上下文，支持 Tab 补全路径
@src/引用整个目录，Claude 会读取其中关键文件
Esc (一次)中断当前生成，已输出内容保留
Esc (两次)退出 Claude Code 会话
Shift+Tab切换 Plan 模式（只规划不执行）
Tab路径自动补全
! command在对话中直接执行 shell 命令（如 !git status）
#keyword触发记忆搜索，回忆之前对话中的内容

高效工作流

  • 先 Plan 再执行：用 Shift+Tab 切规划模式，确认方案后再执行
  • 精准引用：用 @ 指定文件，避免 Claude 搜索无关代码
  • 及时中断：方向错了立刻 Esc

省 token 技巧

  • 需求描述具体比模糊更省
  • 用 @ 定向引用，别满项目搜索
  • 定期 /compact 压缩上下文

核心概念

Skills 技能系统

Skills 是 Claude Code 的可扩展插件——封装特定领域的知识和工作流。

内置 Skills

Claude Code 自带的技能：代码审查、安全审查、初始化等。通过斜杠命令触发。

自定义 Skills

用 Markdown 文件定义 prompt 和行为，放在 ~/.claude/skills/（全局）或项目 .claude/commands/ 下。

Skill 结构

一个 .md 文件 = 一个 Skill。文件名即命令名，文件内容即 prompt 模板。

触发方式

在对话中输入 /skill-name 或 /project:skill-name 即可调用。

Skill 本质是结构化的 prompt——把重复性的复杂任务封装成一键触发的工作流。
进阶

内置 Skill Creator

Claude Code 内置了 Skill 创建能力，帮你快速生成自定义技能。

Step 1
描述需求 — 在对话中告诉 Claude 你想创建什么技能。例如："帮我做一个每次提交前自动检查代码规范的 skill"
Step 2
生成模板 — Claude 会生成 .md 格式的 skill 文件，包含 prompt、触发条件和行为定义
Step 3
放置文件 — 全局 skill 放 ~/.claude/skills/，项目 skill 放 .claude/commands/
Step 4
测试迭代 — 用 /your-skill 触发测试，根据效果修改 prompt 内容

实践建议：好的 Skill = 清晰的触发条件 + 明确的输出格式 + 具体的约束边界。多迭代几次比一次写完美更有效。
