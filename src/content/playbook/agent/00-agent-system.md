Agent 不是一个被包装成聊天界面的模型。它是一个能够观察环境、选择动作、保存状态并根据结果继续推进的执行系统。

## 四个基本组成

一个可工作的 Agent 至少包含四个部分：模型负责判断，状态记录位置，工具影响环境，运行时组织循环。

缺少任何一个部分，系统都容易退化成一次性问答。

## 能力不等于可靠性

更强的模型可以提高单次判断质量，但不会自动解决权限、恢复、验证和长期状态问题。这些能力需要由 Agent 工程系统提供。

## 这本书讨论什么

本书关注 Agent 本身的结构，包括执行循环、状态与记忆、工具使用，以及多个 Agent 如何分工协作。

Harness Playbook 讨论 Agent 外部的工程环境，两本书共同组成一套完整方法。

## 本章检查

- 系统是否区分模型能力与 Agent 能力。
- Agent 是否拥有明确状态与运行循环。
- 工具结果是否能够改变下一次决策。
