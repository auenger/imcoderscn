Agent Loop 决定系统如何从一个目标推进到结果。好的循环不追求动作更多，而追求每次动作都减少不确定性。

## 观察、判断、行动、反馈

每一轮循环都应读取最新环境，判断当前差距，选择一个可验证动作，再把结果写回状态。

## 退出条件

循环必须明确成功、失败、等待和人工介入四种出口。只有最大轮数限制还不够，系统需要知道为什么停止。

## 控制动作粒度

动作过大时难以验证，动作过小时上下文和成本快速增长。合适的动作应该产生一个能够被环境确认的变化。

## 本章检查

- 每轮动作是否减少了目标差距。
- 循环是否拥有明确退出条件。
- 连续失败后是否会改变策略。
