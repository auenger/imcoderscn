状态回答“现在在哪里”，记忆回答“过去学到了什么”。把两者混在对话历史中，会让 Agent 随着任务变长而逐渐失去重点。

## 工作状态

工作状态应包含目标、当前步骤、已确认事实、待处理问题和下一次动作。它需要频繁更新，并服务于恢复。

## 长期记忆

长期记忆保存稳定偏好、重复出现的解决方式和经过验证的领域知识。它不应该记录每一次临时输出。

## 写入门槛

记忆写入需要来源、范围和置信度。未经验证的猜测不应该自动成为长期事实。

## 本章检查

- 当前状态能否支持中断后继续。
- 长期记忆是否只保留可复用信息。
- 记忆是否拥有来源与更新机制。
