工具是 Agent 与环境之间的接口。Agent 工程的重点不只是增加工具数量，而是让系统知道何时调用、怎样组合，以及如何处理结果。

## 工具描述就是行动空间

工具名称、参数和返回结构共同定义 Agent 可以采取的动作。模糊接口会增加错误选择，也让权限控制变得困难。

## 先读后写

面对不确定环境时，Agent 应优先通过只读工具解析目标与当前状态，再决定是否执行修改。

## 结果进入下一轮判断

工具返回需要包含明确状态和可用证据。只返回自然语言描述，会让后续判断失去结构。

## 本章检查

- 工具边界是否与真实领域动作一致。
- Agent 是否在修改前完成必要检查。
- 工具结果是否能够驱动下一轮判断。
